Korisnici mogu:
Dodavati nove narudžbe
Pregledavati postojeće narudžbe
Mijenjati status narudžbi
Izračunavati ukupni iznos računa
Sortirati prikaz narudžbi prema ukupnom iznosu

Struktura narudžbe
Svaka narudžba treba sadržavati sljedeće informacije:
- Ime kupca
- Status (na čekanju, u pripremi, završena)
- Vrijeme narudžbe
- Način plaćanja
- Adresa dostave
- Kontakt broj
- Napomena
- Popis artikala s nazivom, količinom i cijenom
- Iznos i valutu pojedine narudžbe
